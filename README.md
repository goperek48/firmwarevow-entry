One wedding vow, spoken by a robot at its own wedding, for make.fun's "Till Firmware Do Us Part" bounty ($2.50, top 10). One sentence, 118 characters, funny and heartfelt at the same time:

> I vow to love you through every update, every crash, and every low battery, because my heart only ever pairs with you.

## Run it

```sh
python3 main.py
```

`main.py` (Python 3.13, stdlib only) writes the vow to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set), exactly as written, with no trailing newline.
